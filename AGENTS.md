# Project instructions

Read and follow `PUBLISHING.md` before creating, editing, or publishing lessons.
New lessons use the user-approved Google Translate original-speed English audio;
All new lesson audio uses Google; do not include publisher recordings.
Do not generate new Libby audio. Keep audio sources honest and traceable.
Keep existing public URLs stable. Do not publish drafts or voice auditions until
the user approves them. Ordinary requested lesson updates include publication.
