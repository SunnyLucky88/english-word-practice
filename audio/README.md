# Pronunciation audio

- `en-GB/*.mp3`: British English, Microsoft `en-GB-SoniaNeural`, rate -15%, generated with `edge-tts`. Regenerate with `scripts/generate-british-audio.py` after installing `edge-tts`.
- `en-US/*.wav`: American English, Microsoft Zira Desktop, generated with Windows Speech Synthesis.

These are synthesized practice clips, not recordings from the school textbook.
Both accents are served as static files from this repository. Visitors do not
need a system text-to-speech voice or a connection to a speech generation API.
