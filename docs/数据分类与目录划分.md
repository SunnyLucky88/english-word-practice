# 数据分类与目录划分

更新日期：2026-10-24。用户已批准将当前六单元版本发布到原学习入口，完整歌词后续再补。本文描述正式版本的分类与数据结构，制作草稿作为历史依据保留；发布与维护方式见[项目交接与操作说明](项目交接与操作说明.md)。

## 1. 先按教材和单元划分

当前教材为 2025 年人教 PEP 版三年级英语上册。一个单元拥有自己的词汇、课文内容、常用表达、歌曲入口、课本图片和音频目录。不同单元各自保存音频，避免修改一课影响另一课。

英文字母课单独管理。历史“家庭成员与基础词汇”是隐藏测试课，不归入六个正式单元。

## 2. 页面栏目与数据的对应关系

| 页面栏目 | 包含什么 | 数据来源与排列方式 |
| --- | --- | --- |
| 课本点读 | 原图、可点读文字、本页朗读、翻页与放大 | 按课本页码；点读框对应图上的实际文字，本页朗读按实际阅读次序 |
| 单词学习 | 本单元完整单词、中文、音标、课文页码 | 书后 Words in each unit，保持原顺序；不从对话临时抽词代替词表 |
| 句子与歌曲 → 重点表达 | 本单元应掌握的常用表达 | 附录 Useful expressions 第 89—90 页，按单元、按书中顺序 |
| 句子与歌曲 → 课文句子 | 对话、歌谣、阅读、项目示范、例词和字母名称 | 按课本页码分组；字母名称和示例词与完整句子作区分 |
| 句子与歌曲 → 歌曲歌词 | 歌曲名称、歌词、逐句点读和连续朗读入口 | 对应附录 Songs 第 78—79 页；当前只有七个歌曲入口，完整歌词待补充 |
| 小练习 | 看中文想英文、听音选单词、看英文选中文 | 引用上面已有数据，不再维护另一份单词或句子副本 |

小练习默认 **看中文，想英文 / 单词练习**。中文回想范围可切换“单词、重点表达、课文句子”；听音和翻译选择题使用单词。歌曲歌词不进入默认练习。

单词中文释义严格逐字取自对应版本教材书后单元词汇表，保留全部义项、顺序、标点及括号说明，不自行改写。单词卡片、单词回想题、中文选项与中文答题反馈统一引用 `words[].zh`；不维护练习专用释义副本。同词在不同单元按各自词表处理，句子翻译单独维护。完整要求见 [PUBLISHING.md 的教材单词中文释义长期处理规则](../PUBLISHING.md#教材单词中文释义长期处理规则)。

## 3. 单元内部的数据类型

| 数据类型 | 当前字段/位置 | 用途与边界 |
| --- | --- | --- |
| 词汇 | `content.json → words` | 正式词表，含 `en`、`zh`、`ipa`、`page`、`file`、`audioSource`；可用 `ipaDisplay` 保留教材特殊注音排版，例如 `red /red/ panda`，表示教材只给 red 注音 |
| 课文内容条目 | `sentences` | 可朗读文本库；除完整句子，也包含字母名称、例词和标签；不可将条目总数直接称为“完整句子数” |
| 课文分组 | `groups` | `title`、`note`、`clips`；`clips` 是 `sentences` 的 **1 起算编号**，保留课文顺序和重复出现 |
| 常用表达 | `expressions` | `id`、`en`、`zh`、`page`、`file`、`audioSource`；与课文内容可以引用同一音频 |
| 歌曲 | `songs` | `id`、`title`、`zh`、`pages`、`lyricsStatus`、`lines`；当前 `lines` 为空，状态为 `awaiting-user-pages` |
| 课本页 | 正式 `book.js` / HTML 内 `BOOK_PAGES`；草稿另有 `book-pages.json` | 每页的页码、图片、点读框、朗读清单和说明 |
| 音频来源 | `audio/google-v1/sources.json` | 文件名、朗读文字、生成来源 URL、SHA-256；必要时有 `spokenText`，例如 Z 实际生成 zed |
| 练习题池 | 页面运行时由已有数据生成 | 中文回想的课文题池按英文去重，并排除 `practice: false` 的条目；不把字母名称当独立音素题 |

### 页码的含义

- `words[].page`：这个单词在课文中的页码；词表自身位于书后第 83—85 页，两者不能混写。
- `sentences[].page`：条目首次录入时的课文页码。同一句在其他页重现时，实际出现位置由 `groups.note` 和课本页数据确定。
- `expressions[].page`：常用表达附录页码，第 89 或 90 页。
- `songs[].pages`：歌曲附录页码，第 78 或 79 页。
- `BOOK_PAGES[].page`：当前显示的课本页码。

### 点读和本页朗读

图片坐标统一以 1080×1527 为基准。`spots` 的 `box` 为 `[左, 上, 宽, 高]`；`s` 引用课文内容编号，`w` 引用词表中的英文。

`sequence` 是本页朗读清单，允许整数和词汇字符串混合。整数引用 `sentences[编号-1]`，字符串按 `words[].en` 查找。它与点读框是两套用途不同的数据：点读框决定“点击哪里”，朗读清单决定“按什么顺序播放”。

同一句在图上出现两次，本页朗读应保留两次；同一句因换行分成两个框，只朗读一次。不能用全页去重处理这两种情况。

## 4. 复用和去重规则

| 场景 | 规则 |
| --- | --- |
| 课本中同一句多次出现 | 保存各自位置；朗读清单保留每次出现，复用音频文件 |
| 一句话跨两行 | 两个区域都可点读同一句，连续朗读只计一次 |
| 课文句子连续播放 | 使用各组 `clips` 的有序列表，保留重复内容 |
| 中文回想的课文题池 | 按英文去重，避免一道题重复出现；排除 `practice: false` |
| 常用表达与课文完全相同 | 优先引用同单元已有句子的 `file`；没有时再增加音频 |
| 已有词表音频与例词音频 | 可能分别保留历史文件；不按英文文字强制删除或合并 |
| 相同词句在不同单元 | 各单元分别存放，不跨单元引用音频路径 |
| 调整播放速度 | 同一原速文件设 `playbackRate`，保持音高，不新增慢速文件 |

│  └─ docs\                              交接、分类和问题记录

## 7. 编辑时改哪一层

正式版本优先修改以下源文件，再运行打包和全部检查：

| 需求 | 正式修改位置 |
| --- | --- |
| 共同播放、自动滚动、练习交互 | `assets/pep-lesson-app.js` |
| 六单元统一字号、行距与手机文字布局 | `assets/pep-lesson-typography.css`，打包内嵌并计入内容版本 |
| 某单元词汇、表达、歌曲、课文分组 | `assets/日期-主题/content.json` |
| 课本页码、点读框、朗读顺序 | `assets/日期-主题/book.js` |
| 某单元课本原图 | `assets/日期-主题/images/` |
| 原速音频与来源 | `audio/日期-主题/google-vN/` |
| 课程卡片和固定入口 | `courses.json`，再生成首页 |

`scripts/bundle-textbook.cjs` 将正式源数据、共同交互、课本图和控制器打包进课程 HTML。`scripts/check-lesson-runtime.cjs` 检查打包后的实际应用。下面的规则只用于重建保留的制作草稿，不代替正式维护：

- 修改共同交互：改预览根目录 `app.js`，再运行 `apply-audit-fixes.py` 同步六个 HTML。
- 修改附录常用表达或歌曲元数据：改 `appendix-content.py`，重建后准备对应音频并校验。完整歌词需先取得用户提供的第 78—79 页内容。
- 修改已核对的课本朗读顺序或点读框：改 `apply-audit-fixes.py`，不要只改 HTML 中的副本。
- 修改原始课文或词汇：第一、二单元当前取自正式仓库 HTML；第三至第六单元取自 `pep-remaining` 基线。两套来源不要误删，也不要为改草稿直接修改正式课程行为；新增修正应写在预览构建流程中。
- 预览数据是构建结果，直接改 `unitN/content.json` 或 HTML 可能在下次构建被覆盖。
- 本次已按批准范围迁入 `lessons/`、`assets/`、`audio/` 并扩展正式检查；之后的新草稿也不能把整个 `drafts/`、`references/` 或检查截图目录上传。

操作命令见[项目交接与操作说明](项目交接与操作说明.md)，已处理故障见[问题处理记录](问题处理记录.md)。
