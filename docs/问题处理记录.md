# 英语学习页面问题处理记录

记录日期：2026-10-23。用户在最新翻页修复后回复“可以了”。用户未提供具体手机型号和浏览器名称；以下分别记录用户反馈、检查证据和处理方式。

## 1. 课本图片完全不显示

**用户反馈：** 手机浏览器打开，单词、句子能显示，课本图片不显示。

**检查结果：** 16 张图片均为正常 RGB JPEG，线上资源曾通过文件一致性校验。本地也能解码图片。没有取得手机网络日志，因此没有直接证明是哪个请求失败。

**处理：** 将第一单元 4 页、第二单元 12 页课本图，以及课本控制脚本直接打包进课程 HTML；首张图保留静态 HTML 展示，减少额外脚本和图片请求依赖。源图片和 `book.js` 继续保存在 `assets/`，通过打包脚本更新页面。

**验证：** 手机宽度模拟中 16 张图均可解码和展示；两个线上 HTML 与本地文件哈希一致。用户随后确认“现在图片可以显示”。这解决了显示问题，但当时尚未解决用户手机上的翻页问题。

**提交：** `b28953e`。

## 2. 点击下一页，页码变化但图片不变

**用户反馈：** 图片显示恢复后，点击下一页没有加载；进一步确认“页码会变，图片不变”。

**复现证据：** 原脚本先更新页码，然后调用 `canvas.replaceChildren()`。在不支持该方法的 DOM 环境中，产生 `TypeError: canvas.replaceChildren is not a function`，执行在替换图片前中断，表现与用户反馈一致。

**处理：**

- 将课本容器清空改为 `canvas.textContent = ''`，图片和点读按钮通过 `appendChild()` 插入。
- 同时替换小练习清空选项时的 `replaceChildren()`，避免类似兼容问题。
- 更新两个 `assets/.../book.js` 源文件，重新运行打包脚本，更新正式 HTML。
- 新增 `scripts/check-textbook-navigation.cjs` 作为针对该故障的回归检查。

**验证：** 在不支持 `replaceChildren()` 的模拟环境中，两单元全部 16 页均能前后翻页、选择页码，且图片和点读框同步更新；浏览器实际点击下一页后，图片从第 2 页切换为第 3 页并成功解码。两个线上课程 HTML 与修复后的本地文件一致。用户之后确认“可以了”。

**提交：** `1844f74`。没有记录完整手机设备兼容性矩阵，不应据此宣称所有手机浏览器均已验证。

## 后续排查顺序

| 现象 | 优先检查 | 处理和验收 |
| --- | --- | --- |
| 整个页面打不开 | URL、网络、GitHub Pages 构建状态 | 确认构建的是最新提交，再检查公开地址；本地 `127.0.0.1` 链接不能给别人的手机使用 |
| 首页正常，课本空白 | 页面是否旧缓存、HTML 是否包含静态首图和内嵌课本脚本 | 检查公开 HTML 的版本和哈希；重新打包，检查图片 `naturalWidth` 是否大于 0 |
| 页码变、图片不变 | 翻页脚本异常，尤其旧浏览器不支持的 DOM 方法 | 运行翻页回归检查；实际观察图片、页码、点读框是否同步切换 |
| 图片变了，点读位置不对 | 图片比例、点读坐标、页面缩放方式 | 源图保持坐标基准；核对框与文字，检查适合屏幕及放大状态 |
| 点击没有声音 | 媒体音量、实际播放文件、文件是否存在或播放被浏览器拦截 | 在原生播放器手动重试；核对 `AUDIO_BASE`、MP3 解码、加载错误和来源哈希 |
| 发音不满意 | 文本、对应文件、用户已确认的试听版本 | 先提供试听，确认后替换；不能用“文件可解码”代替发音判断 |
| 修改后手机看不到更新 | 页面或音频旧缓存、部署仍未结束 | 等待构建成功；用 `?v=新的提交短号` 临时重开；换音使用新的每课版本目录 |

再次出现问题时，记录：课程链接、单元和页码、手机型号、浏览器名称、点击后页码是否变化，以及其他栏目是否正常。先复现或收集证据，再区分已确认原因与推测。

## 发布时必须保留的防回归措施

1. 不只修改 HTML 内的生成副本；课本逻辑先改 `assets/.../book.js`，再打包。
2. 更改课本后执行 `bundle-textbook.cjs`、`check-courses.cjs`、`check-textbook-navigation.cjs`。
3. 检查每一页的图片与点读框，至少覆盖下一页、上一页和页码跳转。
4. 线上文件核对通过后，才向用户报告已上线；真机与模拟结果分开记录。
5. 分享卡的二维码不换成临时排查地址，也不因修复翻页而更改课程固定 URL。
